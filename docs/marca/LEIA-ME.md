# Amigo Oculto Já! — Kit da marca

Direção escolhida: **Segredo simpático**. Versão 1.0 · 09/10/2026.

1. Leia `amigo-oculto-ja-marca.md`.
2. Para o cabeçalho do app/site, use `logos/logo-principal-transparente.png`.
3. Para uma aplicação pronta sobre carvão, use `logos/logo-fundo-escuro.png` (fundo incorporado).
4. Para o ícone do aplicativo, use `icones/icone-app-1024.png`.
5. Para o navegador, use `icones/favicon.ico` ou os PNGs da mesma pasta.
6. Para cores da interface, consulte `implementacao/tokens.css` e `implementacao/tokens.json`.
7. A referência visual aprovada está em `referencia/prancha-aprovada.png`.

As imagens são PNGs raster; as versões transparentes têm canal alfa. Este kit não contém arquivo vetorial nem a fonte exata do logotipo. Use as imagens fornecidas; Figtree é a indicação de fonte para textos da interface.

O botão desenhado na arte de divulgação faz parte da imagem: adicione o link real na plataforma de publicação.

Veja o arquivo `inventario.json` para dimensões e identificação dos arquivos.
