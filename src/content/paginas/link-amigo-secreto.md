# Link de amigo secreto: como criar e mandar para o grupo

**O link de amigo secreto é o endereço que você manda para o grupo depois do sorteio. Cada pessoa abre, toca no próprio nome e vê só quem tirou.** No Amigo Oculto Já, o link fica pronto assim que você sorteia, e funciona igual para amigo oculto.

## Como criar o link

1. [Crie o grupo](/criar/nome) e escreva os nomes.
2. Defina o valor do presente, a data e as exclusões.
3. Toque em **Sortear** e entre com Google ou e-mail.
4. O link aparece na tela. Toque em **WhatsApp** para mandar com a mensagem pronta, ou em **copiar** para mandar onde quiser.

## O que a pessoa vê ao abrir o link

- O nome do grupo, o valor do presente e a data da troca.
- A lista de nomes, para tocar no próprio.
- Quem tirou, depois de tocar no nome.
- A lista de desejos de quem tirou, quando essa pessoa já tiver feito.

Ela não precisa de conta nem de app. O app para iPhone e Android existe, mas é opcional.

## Um link para todos ou um link para cada um?

| | Link do grupo | Link individual |
| --- | --- | --- |
| Para quem | família, amigos, grupos pequenos | empresas, turmas grandes |
| Como manda | uma mensagem no grupo | um link por pessoa, no privado ou por e-mail |
| O que a pessoa faz | toca no próprio nome | já entra com o nome certo |
| Onde ativa | padrão | [modo empresa](/empresas) |

## Por que o link é seguro

- **Cada nome só pode ser escolhido uma vez.** Depois disso, fica ligado ao aparelho de quem escolheu.
- **O sorteio roda no servidor.** Nem quem organiza vê quem tirou quem.
- **Quem organiza acompanha sem espiar.** O painel mostra quem abriu o link e quem viu o resultado, nunca os pares.

## Onde mandar o link

- [Pelo WhatsApp](/amigo-secreto-pelo-whatsapp), no grupo ou no privado.
- [Por e-mail](/amigo-secreto-por-email), bom para o trabalho.
- Por SMS, Slack ou Teams: copie e cole.
