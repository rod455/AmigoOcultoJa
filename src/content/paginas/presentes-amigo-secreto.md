# Presente de amigo secreto: ideias por valor e por perfil

**O jeito mais garantido de acertar o presente de amigo secreto é a pessoa dizer o que quer: uma lista de desejos com 2 ou 3 itens dentro do valor combinado.** Quando não há lista, escolha um presente coringa, que serve para quase todo mundo. Abaixo estão as ideias por valor e por perfil, que valem também para amigo oculto.

## Antes de comprar: 3 perguntas

1. **Qual é o valor combinado?** Fique nele. Gastar muito a mais também constrange.
2. **A pessoa fez lista de desejos?** No Amigo Oculto Já, quem tirou a pessoa vê a lista na hora, no mesmo link do sorteio.
3. **O presente serve para quem eu tirei, ou para mim?** Presente bom é sobre a outra pessoa.

## Por que a lista de desejos resolve

No sorteio do Amigo Oculto Já, cada pessoa pode montar uma lista com até 3 itens: sugestões dentro do valor combinado, o link de um produto ou um texto livre ("gosto de café", "não uso perfume"). Quem a tirou vê a lista na hora. Ninguém precisa perguntar para os outros e estragar o segredo. Precisa presentear muita gente de uma vez? Veja [lembrancinha de Natal](/lembrancinha-de-natal).
